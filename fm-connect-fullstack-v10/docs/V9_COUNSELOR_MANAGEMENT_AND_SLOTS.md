# V9 Counselor Management and Availability Slots

## Summary

This version adds the missing counselor creation and counselor availability workflows.

## Admin workflow

Admin can:
- Create counselor profile and login account together.
- Edit counselor profile fields.
- Manage counselor visibility/status.
- Add/edit/delete counselor availability slots.
- Add online meeting link or physical location.
- Manage availability on behalf of a counselor.

## Counselor workflow

Counselor can:
- View bookings.
- View dashboard stats.
- Add available booking slots.
- Edit slots.
- Delete non-booked slots.
- Disable slots when needed.
- Add online or physical session information.

## Student workflow

Student can:
- View available counselor slots on the public Counseling page.
- Book available slots.
- See booking confirmation in the student dashboard.

## Slot fields

- Date
- Start time
- End time
- Mode: Online or Physical
- Meeting link
- Location
- Capacity
- Status: AVAILABLE, BOOKED, DISABLED, CANCELLED
- Notes
