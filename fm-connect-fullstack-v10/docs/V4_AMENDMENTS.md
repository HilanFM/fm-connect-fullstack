# FM Connect v4 Amendments

## Contact / Reach Us / Inquiry

Added a public Contact page and homepage inquiry section. Inquiries are stored in the JSON demo database under `inquiries`. Admin users can view and resolve inquiries from the Admin Dashboard.

## Dashboard Stats

Added Stats tabs for Student, Institute Owner, Counselor, and Admin dashboards. These show demo KPIs such as courses, leads, inquiries, published courses, counseling slots, and videos.

## Video Sections

Added public videos, homepage video highlights, institute profile videos, course detail videos, Institute Owner video management, and Admin video management.

## Notes

This is still a demo/starter system. For production, replace JSON storage with PostgreSQL/MySQL, add real authentication, real media storage, secure validation, and production hosting.
