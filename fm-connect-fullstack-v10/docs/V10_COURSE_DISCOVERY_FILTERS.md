# V10 Course Discovery Filters

Added richer Course Discovery filters for the demo app.

## New filters
- Keyword search
- Category
- Location
- Course type
- Study mode
- Cost range
- Duration
- Institute
- Sponsored / regular listing
- Sort by best match, rating, cost, duration, or newest intake

## Notes
The demo keeps filtering in the frontend for simplicity. In production, these filters should be moved to backend/search service queries for performance and analytics.
