# Admin and Institute Owner Workflows Added in v2

## Institute Owner
1. Login as institute@fmconnect.lk / demo123.
2. Open Institute Dashboard.
3. Use Institute Profile tab to edit institute details and image.
4. Use Courses / Degrees tab to create new courses.
5. Expand any course row to edit title, category, type, status, price, images, modules, skills, and related jobs.
6. Delete courses using the Delete Course button.
7. Use Leads tab to view student enrollment and interest requests.

## Admin
1. Login as admin@fmconnect.lk / demo123.
2. Open Admin Dashboard.
3. Use Institutes tab to create institutes and owner users.
4. Use Users tab to create or update users.
5. Use Courses tab to create, edit, or delete courses for any institute.
6. Use Institute Requests tab to approve or convert requests into institute accounts.
7. Use Content tab to approve articles and feedback.
