## Recommended production image sizes

- Homepage hero: 1600 × 900 px
- Course cards: 1200 × 720 px
- Institute banners: 1200 × 720 px
- Profile/logo images: keep separately as square assets where needed

## Production note

For production, institute-uploaded images should be stored in cloud object storage such as S3, Azure Blob, or Google Cloud Storage, and delivered through a CDN.
