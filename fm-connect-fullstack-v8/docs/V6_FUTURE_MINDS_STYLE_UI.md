# V6 Future Minds Style UI Upgrade

## Purpose

Upgrade the FM Connect public experience so the hosted demo looks like a more realistic education marketplace / career guidance platform.

## Added / improved

- Homepage hero with Future Minds inspired message and stronger visual treatment.
- Search bar with course, category, location, and study level fields.
- Featured institute cards.
- Featured degree/course cards.
- Blue stats band.
- Video highlights section.
- Career counseling feature section.
- Testimonials section.
- Contact Us section.
- Institute profile hero, metrics, tabs, gallery, videos, contact sidebar, open day, intake, and course sections.
- Course detail hero, facts, modules, videos, related careers, and CTA actions.
- Improved responsive styling.

## Existing functionality retained

- Student, Institute, Counselor, and Admin logins.
- Institute profile editing.
- Course/degree add/edit/delete.
- Admin institute and user creation.
- Video management by admin, institute, and counselor.
- Contact Us inquiry management.
- Demo JSON data store.
